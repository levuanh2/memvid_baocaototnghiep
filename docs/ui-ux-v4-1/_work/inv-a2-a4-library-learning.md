## Scope and mount status

- **LIVE routes:** `FE/src/App.jsx:73-79` mounts `/app/study`, `/app/study/quiz/new`, `/app/study/quiz/:quizId`, `/app/study/result/:attemptId`, `/app/study/review/:attemptId`, and `/app/study/practice/:quizId`.
- **LIVE workspace tools:** `FE/src/pages/Workspace.jsx:3,47` mounts `MainLayout`; `FE/src/components/Layout/MainLayout.jsx:617-629,922-990` mounts `StudyToolsMenu` and `SidebarRight`, which in turn mount `TutorPanel` and `KnowledgeDashboard`.
- **NOT MOUNTED:** `r71qa`, `round6LibraryQa`, `fixtureHarness`, and `dev/` code has no import chain from the routes above. The legacy inspector tab strip in `SidebarRight.jsx:918-959` is also not mounted because `legacyInspectorSurfacesEnabled` is hard-coded `false` at `SidebarRight.jsx:32`; the Tutor/Timeline/Knowledge content remains reachable through `StudyToolsMenu`.
- **Library flag:** `FE/src/utils/libraryActionMatrixFlag.js:1-2` enables the matrix only when `VITE_LIBRARY_ACTION_MATRIX` equals `"true"` (case-insensitive). No live source sets a fallback, so unset/false is the production/default **OFF** UI (`StudyCard` sections); true is the **ON** UI (`LibraryTaskViews` + `StudyDocumentActionRow`). Upload, sidebar, filters, bulk bar, AI insight, and Learning Dashboard are shared by both states.

## Possible duplicates

- **Upload entry points — SAME behavior:** header `Tải tài liệu` (`DocumentList.jsx:510-518`) and no-document CTA `Tải tài liệu` (`DocumentList.jsx:837-860`) open the same file input and end at `POST /api/documents/upload`. `Tải lại tài liệu` (`AiInsightCard.jsx:72-75`) also reaches the same picker/API, but is state-specific recovery after an ingest error.
- **Archived visibility — SAME behavior:** sidebar and toolbar both label `Hiện đã lưu trữ` (`CollectionSidebar.jsx:232-239`; `DocumentList.jsx:661-666`) and mutate the same `hienLuuTru` state; the sidebar copy is desktop-only.
- **Favorite/pinned filters — similar labels, different filter semantics:** sidebar `Yêu thích`/`Đã ghim` (`CollectionSidebar.jsx:227-229`) selects a shortcut context, while toolbar filters (`DocumentList.jsx:58-64,616-645`) participate in a multi-filter array.
- **Summary entry points — SAME destination, state-dependent outcome:** OFF card `Tóm tắt` (`StudyCard.jsx:120,284-300`), details `Mở/Tạo tóm tắt` (`KnowledgePanel.jsx:290-304`), AI insight (`AiInsightCard.jsx:72-75`), and ON row primary/quick/tools (`StudyDocumentActionRow.jsx:45-89`; `DocumentToolsSheet.jsx:7-20`) all call the summary surface resolver. Whether the surface opens or generates depends on document state.
- **Diagram labels — not always the same behavior:** OFF `Sơ đồ` and AI insight `Tạo/Mở sơ đồ` use `studymap` (`StudyCard.jsx:121`; `AiInsightCard.jsx:23-28`), whereas ON quick `Sơ đồ tư duy` uses `mindmap` (`StudyDocumentActionRow.jsx:86-89`); the full ON tools menu exposes both `Sơ đồ tư duy` and `Bản đồ học tập` (`DocumentToolsSheet.jsx:7-10`).
- **Quiz entry points — SAME resolver but context changes:** OFF `Quiz`, ON `Tạo quiz`/`Quiz`, and Library `Xem thử` (`StudyCard.jsx:122`; `libraryActionMatrix.js:125-145`; `DocumentToolsSheet.jsx:10`; `DocumentList.jsx:521-526`) use the document quiz resolver, which opens an existing latest quiz when present or the setup route otherwise.
- **Review entry points — SAME resolver, possible fallback:** OFF/ON `Ôn tập` and Learning Dashboard review-queue titles (`StudyCard.jsx:123`; `DocumentToolsSheet.jsx:11`; `LearningDashboard.jsx:214-218`) request the review surface, but resolution can fall back to StudyMap when no latest attempt exists.
- **Single vs bulk management — similar label, different scope/API:** card/menu `Ghim`, `Yêu thích`, `Lưu trữ` uses `PATCH /api/documents/{id}` (`StudyCard.jsx:198-223`; `DocumentToolsSheet.jsx:18-20`); BulkBar uses `POST /api/documents/bulk` (`BulkBar.jsx:47-142`). Bulk actions do not expose the inverse labels shown by single-document menus.
- **Quiz submission launchers — SAME behavior:** `Nộp bài sớm` and footer `Nộp bài` (`QuizTaking.jsx:259-261,336-339`) only open the same confirmation. The dialog's `Nộp bài` (`QuizTaking.jsx:405-416`) is the action that actually saves and submits.
- **Review-plan links in result — SAME route:** header `Kế hoạch ôn tập` and both responsive/next-step `Mở kế hoạch ôn tập` links (`QuizResult.jsx:123-125,289-291`) go to `/app/study/review/{attemptId}`.
- **Wrong-answer review vs review plan — similar learning goal, different behavior:** `Xem lại {N} câu cần ôn` (`QuizResult.jsx:272`) stays inside the result and pages through answers; `Mở kế hoạch ôn tập` (`QuizResult.jsx:289-291`) navigates to the generated review workflow.
- **Tutor `Kiểm tra nhanh` vs Library `Tạo quiz` — similar label only:** Tutor sends a three-question chat prompt (`TutorPanel.jsx:84-92`; `tutorActions.js:25-32`); Library creates/opens a persisted quiz and attempt.
- **Tutor `Tóm tắt lại`/`Xem tóm tắt` vs Library summary — different behavior:** `Tóm tắt lại` sends a chat prompt and `Xem tóm tắt` switches the workspace artifact (`TutorPanel.jsx:84-92`); Library summary actions navigate to the document summary surface.
- **Tutor `Ôn lại phiên này` vs Review/Practice — similar label only:** Tutor synthesizes a chat recap from session memory (`TutorPanel.jsx:94-98`; `tutorActions.js:39-55`); Review Guide and Practice use persisted attempts, plans, generated quizzes, and APIs.
- **Progress/score presentation repeats, but is not an action duplicate:** Library Overview (`DocumentList.jsx:938-957`), Learning Dashboard, Quiz Result, Review Guide mastery badges, and Practice comparison all display overlapping progress/mastery/score concepts with different scopes (library-wide, document, attempt, concept, before/after).

## Confusing labels

- `Sơ đồ` in the production/OFF card means **Bản đồ học tập (`studymap`)**, while `Sơ đồ tư duy` in the ON quick action means **mindmap**; `Tạo sơ đồ`/`Mở sơ đồ` in AI Insight also mean `studymap`.
- `Ôn tập`, `Kế hoạch ôn tập`, `Kế hoạch ôn`, `Xem lại ... câu cần ôn`, `Luyện ngay`, and Tutor's `Ôn lại phiên này` describe five materially different scopes: route resolution, persisted review plan, back-link, local wrong-answer review, generated practice, and chat recap.
- `Quiz`, `Tạo quiz`, and `Kiểm tra nhanh` are not interchangeable: Library quiz actions resolve a persisted quiz/setup flow; Tutor `Kiểm tra nhanh` starts a three-question chat exchange.
- `Tiếp tục học` is both a matrix filter and a section heading; `Tiếp tục · {surface}` is an action. The first two select/group documents, while the latter navigates.
- `Xem thử` does not open a preview of the highlighted/filtered item; it chooses a ready document from the full library and opens one of its ready learning surfaces.
- The two visible `Hiện đã lưu trữ` controls are the same state, but one disappears below `lg`, which can make the toolbar copy look like a separate option when resizing.
- Library Overview `Điểm trung bình`, Quiz Result score, Review Guide mastery, Learning Dashboard completion/readiness, and Practice `Trước`/`Sau` share score/progress vocabulary but use different denominators and scopes.
- `Viết lại` means force-regenerate the entire persisted review plan, not edit its prose or retry one item.
- `Bỏ chọn, ra đề toàn tài liệu` clears section IDs; `Bỏ chọn` in BulkBar clears selected documents. Same imperative, unrelated selection scopes.
- `Xoá` in CollectionSidebar deletes a collection but preserves its documents; `Xoá` in BulkBar hides/deletes selected documents from the library after a native confirmation.
