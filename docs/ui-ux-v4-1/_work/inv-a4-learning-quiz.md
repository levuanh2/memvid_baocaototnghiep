## Possible duplicates

- `Tạo quiz`: library/document surfaces route to `/app/study/quiz/new?document=...` (route owner `App.jsx:75`), while setup CTA `Tạo quiz` (`QuizSetup.jsx:202-205`) actually calls `POST /api/quizzes/generate` — **similar label, different behavior/stage**.
- Quiz `Nộp bài sớm` (`QuizTaking.jsx:259`) and sticky `Nộp bài` (`QuizTaking.jsx:336-338`) both only open the same confirmation; dialog `Nộp bài` (`QuizTaking.jsx:413-415`) performs the API submit — first two are **SAME behavior**, final is a distinct confirmed action.
- `Kế hoạch ôn tập` in result header (`QuizResult.jsx:123-125`) and both `Mở kế hoạch ôn tập` placements in wrong-answer review (`QuizResult.jsx:289,291`) all route to `/app/study/review/{attemptId}` — **SAME navigation**, latter pair are responsive duplicates.
- `Luyện ngay (5 câu)` (`ReviewGuide.jsx:227-229`) and dialog `Tạo câu luyện tập` (`ReviewGuide.jsx:259-265`) call the same `practise` pipeline and same review item — **SAME scope/API**, but quick uses fixed 5/easy/backend-default types; customized passes explicit count/difficulty/types.
- `Kế hoạch ôn` in Practice (`Practice.jsx:98-102`) returns to the same review route that launched practice — **SAME plan destination** as result links, but preserves `source_attempt_id` from the generated practice quiz.
- Tutor `Kiểm tra nhanh` (`TutorPanel.jsx:84-89`, `tutorActions.js:24-29`) only drafts a chat prompt for three questions; `Tạo quiz` (`QuizSetup.jsx:202-205`) creates a persisted quiz/job — **similar learning goal, not the same behavior**.
- Tutor `Ôn lại phiên này` (`TutorPanel.jsx:95-96`) drafts a chat recap from session memory; `Kế hoạch ôn tập`/`Luyện ngay` use graded attempt/mastery and persisted review items — **similar label/goal, different evidence, scope, and persistence**.

## Confusing labels

- `Hôm nay`, `Ngày mai`, `Sau` in `LearningDashboard.jsx:97-102` look scheduled, but `reviewQueue.js:5-8,29-45` explicitly derives them only from mastery bands; there is no due date or scheduler.
- Dashboard repeats related but non-equivalent percentages: `Hoàn thành`/coverage (`LearningDashboard.jsx:42-49`), `Điểm quiz trung bình` (`:52`), per-document `readiness.total` (`:78`), and mastery seals (`:216`). They use different denominators/meaning, despite adjacent `%` presentation.
- Result score hero shows raw quiz percentage/score (`QuizResult.jsx:224-270`), while `Mức nắm theo chủ đề` uses `mastery_score` (`:180-197`); Practice then shows both a new practice score (`Practice.jsx:107-127`) and before/after mastery (`:207-252`). These are not interchangeable progress numbers.
- `Luyện tập` is not a general free practice route: generation always starts from one `review_item_id` (`ReviewGuide.jsx:83-91`), so scope is one review-plan topic even when the customization dialog changes question count/types/difficulty.
- `Làm lại` is not present as a LIVE A4 label in the audited files. The available next steps are `Xem lại ... câu cần ôn`, `Mở kế hoạch ôn tập`, and topic-scoped `Luyện ngay`; none reruns the original quiz attempt.
- `Viết lại` (`ReviewGuide.jsx:112-116`) regenerates the **review plan** with `force=true`; it does not rewrite answers, retry grading, or create practice questions.
- `Ôn tập` in `learningJourney.js:42` is a milestone marked when a review plan exists (`review_created`), not proof that the learner completed practice. Likewise the journey's final state is plan creation, because no separate finished flag exists (`learningJourney.js:34-39`).
- `AI đã đọc xong tài liệu này` from `aiInsight.js:75-88` means a real summary exists; upload/index readiness alone uses `Đã sẵn sàng tra cứu` (`:60-73`). It is an insight-state distinction, not quiz mastery/readiness.
