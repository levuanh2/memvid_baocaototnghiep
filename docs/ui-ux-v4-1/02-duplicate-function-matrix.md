# 02. Duplicate function matrix

Decision values: KEEP, MERGE, MOVE, RENAME, DISCLOSE, REMOVE.
Type: **UI** = same behavior shown twice; **BEH** = different labels, same
behavior; **CTX** = intentional contextual shortcut; **SIM** = similar label,
different behavior; **FLAG** = hidden behind a flag; **DEAD** = rendered but
does nothing; **LEGACY** = unmounted code.

Confusion: H high, M medium, L low. Screens: `evidence/screens/`. Verification
scripts: `evidence/capture/`.
